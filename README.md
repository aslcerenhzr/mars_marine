# mars_marine

 "Mars Marine" was one of my first projects in Unreal Engine 5. In this game, enemies spawn in waves, appearing at one of ten predefined locations chosen at random, and the player must fight them off. After taking damage, the player can restore health by collecting pickups scattered around the map. If their health reaches zero, it's game over. This project gave me the opportunity to explore Unreal Engine 5’s animation system and UI integration in greater depth. Later, I added a menu level and fixed some bugs.
